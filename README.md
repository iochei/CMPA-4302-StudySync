# StudySync

CMPA 4302 – Project 01: Product Concept Package
Texas Tech University
Ian-Bradley Ochei

## Overview

StudySync is an interactive study planning prototype
designed to help working college students balance
academic and employment responsibilities.

## Core Features

- Study availability management
- Assignment and deadline tracking
- Personalized study plan generation
- Flexible schedule adjustments
- Insufficient study time alerts

## Technologies

- HTML
- CSS
- JavaScript

https://iochei.github.io/CMPA-4302-StudySync/
